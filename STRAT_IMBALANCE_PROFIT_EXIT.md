# Imbalance Profit Exit

Java-класс: `ImbalanceProfitExitStrategy`.

## 1. Основа стратегии

Стратегия копирует текущее поведение `BaseImbalanceStrategy`:

- окно TOP5 стакана — 120 секунд;
- сильный imbalance окна — перевес строго больше `1.6`;
- aggression-окно — 120 секунд;
- сильный aggression — перевес строго больше `1.01`;
- BUY-сигнал возникает, когда TOP5-окно и aggression одновременно показывают BUY;
- SELL-сигнал возникает, когда TOP5-окно и aggression одновременно показывают SELL;
- моментальный TOP20 рассчитывается с коэффициентом `1.05`, но сейчас не участвует
  в итоговом условии сигнала;
- при отсутствии сильного сигнала базовая стратегия отменяет оба ордера;
- цена направленного ордера, order size, hard limit и остальные safety-правила
  наследуются от S0 так же, как в `BaseImbalanceStrategy`.

Единственное новое поведение — прибыльный пассивный ордер, уменьшающий открытую
позицию.

## 2. Новый параметр

`minimumExitProfit` — минимальная прибыль в USD на 1 ETH относительно средней цены
входа. Значение обязательно задается при создании стратегии и не может быть
отрицательным.

Комиссия в условие не включается. При текущем `makerFeeBps = 0` проверяется gross
разница цен.

## 3. Данные о позиции

В `decide()` передаются:

- `inventory`;
- `averageEntryPrice`.

Отдельная сторона позиции не нужна:

- `inventory > 0` — long;
- `inventory < 0` — short;
- `inventory == 0` — позиции нет.

## 4. Прибыльный уменьшающий ордер

Для long можно выставить только ask:

```text
bestAsk - averageEntryPrice >= minimumExitProfit
```

Для short можно выставить только bid:

```text
averageEntryPrice - bestBid >= minimumExitProfit
```

Ордер ставится по текущему best bid/ask. Если текущая лучшая цена не дает заданную
прибыль, удаленный ордер по целевой цене не выставляется.

Размер exit-ордера не может перевернуть позицию:

```text
exitSize = min(orderSize, abs(inventory))
```

## 5. Решение по ордерам

### Сильный BUY-сигнал

- bid выставляется по правилам `BaseImbalanceStrategy`;
- если есть long и текущий best ask дает `minimumExitProfit`, дополнительно
  выставляется уменьшающий ask;
- иначе ask отменяется.

### Сильный SELL-сигнал

- ask выставляется по правилам `BaseImbalanceStrategy`;
- если есть short и текущий best bid дает `minimumExitProfit`, дополнительно
  выставляется уменьшающий bid;
- иначе bid отменяется.

### Сильного сигнала нет

- при long выставляется только прибыльный уменьшающий ask;
- при short выставляется только прибыльный уменьшающий bid;
- при flat оба ордера отменяются;
- если текущая цена не дает `minimumExitProfit`, оба ордера отменяются.

## 6. Важное поведение

- При противоположном сильном сигнале направленный ордер может закрыть позицию с
  убытком и затем открыть позицию в сторону сигнала. Profit-фильтр его не ограничивает.
- Profit-exit всегда только уменьшает текущую позицию и не может перевернуть ее.
- После изменения average entry price условие и размер exit-ордера рассчитываются
  заново.
- Stale book, gaps, latency, очередь, fills, комиссии и hard inventory limit не
  меняются.

## 7. Ограничение гипотезы

Стратегия быстрее фиксирует прибыльные позиции, но может долго удерживать убыточные.
Поэтому результат нужно оценивать по total mark-to-market PnL, inventory и drawdown,
а не только по realized PnL или числу прибыльных закрытий.
